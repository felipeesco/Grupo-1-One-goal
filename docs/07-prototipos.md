# 07 · Prototipo
## Hipótesis del prototipo
| | |
|---|---|
| **Qué vamos a construir** | Una página web para registrar los pedidos diarios de
la panadería. |
| **Tipo de prototipo** | Página web |
| **Usuario** | Encargada de pedidos |
**Hipótesis**
> Creemos que la encargada de pedidos podrá dejar de perder pedidos anotados en
papel si usa una página donde los registra y los ve en una lista.
**Sabremos que es cierto si:** en una semana de prueba no se pierde ningún pedido.
## Versión 0.1
**Qué tiene la v0.1:**
1. Pantalla para registrar un pedido (cliente, producto, cantidad, hora de
entrega).
2. Lista de pedidos del día.
3. Botón para marcar un pedido como entregado.
